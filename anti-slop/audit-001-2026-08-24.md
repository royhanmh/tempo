# antislop Audit 001 - Tempo

Date: 2026-08-24
Scope: `src/` React app (Home, Focus, components, store)
Mode: AFTER (audit existing work)

Design Read: personal timer workspace app for a single user, warm minimal Nordic style (from prototype tokens), dial ENERGY 1 / RHYTHM 1 / MOTION 1.

## Findings

### HIGH (Hard Gate)

1. **R-37 - No DESIGN.md.** The UI was built from prototype tokens without a written design direction file. The palette and type choices are real (ported from prototype.html) but undocumented. Fix: write DESIGN.md capturing the existing tempo palette, Inter/Space Mono choice reasons, and dials. One file, no visual change.

2. **R-32 - Modal not closable with Escape.** CreateTimerModal closes on backdrop click and X button only. Keyboard users cannot dismiss it with Escape. Fix: add keydown listener in Modal.jsx.

3. **R-27 - No timers empty state missing.** Search-empty and history-empty states exist, but when `timers` array is fully empty the main area renders nothing (activeTimer null, grid hidden). User sees blank page with no guidance. Fix: add an empty state that says no timers yet with a create action.

4. **R-25 - Muted text contrast borderline.** `text-tempo-muted` (#7E828D) on `bg-tempo-bg` (#F5F4F0) computes to roughly 4.0:1, below the 4.5:1 AA bar for the small text sizes it is used at (labels, timestamps). Fix: darken muted to about #6B6F7A in light theme (verify with checker).

5. **R-03 - Tap targets under 44px on mobile.** TimerCard start/pause buttons are 32px (w-8 h-8); icon-only header buttons are smaller than 44px hit area. Fix: add padding/hit-box expansion at mobile, keep visuals.

### MEDIUM (Purpose-Gate)

6. **R-11 - Pill radius as default.** Nearly every control is rounded-full (buttons, search, theme switcher, badges) while cards are rounded-3xl and inputs rounded-xl. Radius reads as default rather than deliberate system. Fix: define two radii (pill only for primary round actions, xl for secondary controls) or write the reason down.

7. **R-09 - Status dot pulse loop.** The emerald dot on ActiveTimer uses animate-pulse forever. Purpose (signals live/running state) is real but never stated, and it pulses even when timer is idle. Fix: state purpose in comment/class name and only pulse while running.

8. **R-29 - Five accent colors active.** Timer cards use green/orange/red/purple/blue accents chosen by the user per timer. A design system exists (ACCENTS map) so this is defensible, but the reason is undocumented. Fix: document that accents are user-assigned category colors, or reduce default set.

9. **R-14 - Uniform timer cards.** All TimerCards share identical layout. Hierarchy reason exists (they are peers in a grid, hero card carries hierarchy) but is unwritten. Fix: one-line comment documenting the hierarchy decision.

### LOW (Quality Locks)

10. **antislop-code - Section label comments.** Comments like `{/* Desktop sidebar */}`, `{/* Main */}` restate the obvious JSX below them. Fix: remove or keep only where the block is non-obvious.
